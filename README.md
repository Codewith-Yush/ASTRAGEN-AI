## 🌟 Overview

**AstraGen AI** is a production-grade SaaS application designed to empower creators, developers, marketers, and researchers with AI-driven content acceleration. 

Unlike traditional wrappers that break during API rate spikes, AstraGen AI features a **multi-provider failover engine** with intelligent cooldown management: requests seamlessly fall back across **Google Gemini**, **Groq**, and **OpenRouter** without interrupting the user experience.

Combined with **Neon Serverless PostgreSQL**, **Drizzle ORM**, **Clerk v7 Authentication**, and **Razorpay Subscriptions**, AstraGen AI is a complete, scalable SaaS blueprint.

### 💡 Why AstraGen AI?

| Problem in Standard AI Tools | The AstraGen AI Solution |
| :--- | :--- |
| **API Outages & 429 Rate Limits** | Automatic 3-tier cascade (`Gemini 3.x` ➡️ `Groq` ➡️ `OpenRouter`) ensures **99.9% uptime**. |
| **Generic & Hallucinatory Output** | 25+ domain-specialized templates with fine-tuned system instructions and structured schemas. |
| **Static, Boring Generation** | Real-time streaming markdown renderer with syntax highlighting, word counters, and live refinement. |
| **Complex Billing Integration** | Built-in Razorpay subscription checkout with cryptographically verified webhook handlers. |
| **Lack of Usability History** | Persistent Neon PostgreSQL content archive with instant keyword search, copy, and export options. |

## 🏗️ System Architecture

AstraGen AI implements a resilient, serverless-first data flow designed for maximum throughput and fault tolerance:

```mermaid
flowchart TD
    subgraph Client["🖥️ Client Layer (Next.js 15 App Router)"]
        UI["Modern UI / Responsive Dashboard"]
        Form["25+ Domain Form Sections"]
        Output["Streaming Markdown & Syntax Highlighter"]
    end

    subgraph AuthSecurity["🔒 Auth & Protection"]
        Clerk["Clerk Auth (JWT & Session Validation)"]
        RateLimiter["Server-Side Rate & Credit Meter"]
    end

    subgraph ResilienceEngine["⚡ Multi-Provider AI Fallback Matrix"]
        Primary["Google Gemini 3.1 / 3.5 Flash<br/>(Primary Provider)"]
        Groq["Groq Engine (GPT-OSS / Llama)<br/>(Fallback 1 on 429/Timeout)"]
        OpenRouter["OpenRouter Free Models<br/>(Fallback 2 on Cooldown)"]
    end

    subgraph StorageMonetization["💾 Persistence & Billing"]
        Neon["Neon Serverless PostgreSQL"]
        Drizzle["Drizzle ORM (Compound Indexes)"]
        Razorpay["Razorpay Subscriptions + Webhooks"]
    end

    UI --> Form
    Form --> Clerk
    Clerk --> RateLimiter
    RateLimiter --> Primary
    Primary -- "429 / Timeout / Failover" --> Groq
    Groq -- "Failover / Cooldown" --> OpenRouter
    Primary & Groq & OpenRouter --> Output
    Output --> Drizzle
    Drizzle --> Neon
    Razorpay -- "Verified Webhook" --> Drizzle
```

## 🏁 Getting Started

Follow these steps to set up AstraGen AI locally in minutes.

### 📋 Prerequisites

- **Node.js**: `v18.17.0` or higher (Node 20+ recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`
- **Neon Account**: Free serverless Postgres database at [neon.tech](https://neon.tech)
- **Clerk Account**: Free authentication setup at [clerk.com](https://clerk.com)
- **Google Gemini API Key**: Free API key from [Google AI Studio](https://aistudio.google.com/)

### ⚡ Quick Installation

```bash
# 1. Clone the repository
git clone https://github.com/Codewith-Yush/ASTRAGEN-AI.git

# 2. Enter project directory
cd ASTRAGEN-AI

# 3. Install dependencies
npm install

# 4. Create your local environment file
cp .env.example .env.local

# 5. Push schema to your Neon PostgreSQL database
npm run db:push

# 6. Launch the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to start creating.

## 🔐 Environment Configuration

Create a `.env.local` file in the root directory and configure the following keys:

```ini
# ==========================================
# 🗄️ DATABASE (Neon Serverless PostgreSQL)
# ==========================================
DATABASE_URL=postgresql://<user>:<password>@<ep-xyz>.neon.tech/neondb?sslmode=require

# ==========================================
# 🔒 AUTHENTICATION (Clerk)
# ==========================================
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=/dashboard
NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL=/dashboard

# ==========================================
# 🧠 AI ENGINE (Multi-Provider Setup)
# ==========================================
# Primary Provider: Google Gemini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.1-flash-lite

# Fallback Provider 1: Groq (Optional, highly recommended)
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-120b,openai/gpt-oss-20b

# Fallback Provider 2: OpenRouter (Optional free models)
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_MODEL=google/gemma-4-31b-it:free,openrouter/free

# Provider Execution Order
AI_PROVIDER_ORDER=gemini,groq,openrouter

# ==========================================
# 💳 PAYMENTS & BILLING (Razorpay)
# ==========================================
NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_test_...
RAZORPAY_KEY_ID=rzp_test_...
RAZORPAY_SECRET_KEY=your_razorpay_secret
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
SUBSCRIPTION_PLAN_ID=plan_...

# ==========================================
# 📧 EMAIL SMTP (Nodemailer Support Form)
# ==========================================
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_SECURE=false
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_app_specific_password
CONTACT_RECEIVER_EMAIL=support@astragen.ai
```
